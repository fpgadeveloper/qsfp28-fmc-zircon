# Licensing

The design combines sources under three different licenses. Read this page before you ship a
product built from it.

## What is licensed how

| Part | Where | License |
|------|-------|---------|
| Everything Opsero wrote: the `zircon_nic` glue logic and register file, the MRMAC adapters, the testbench, the block design, the constraints, the bare-metal application, the host test scripts, the build scripts and this documentation | everything outside `submodules/` | **MIT** (see `LICENSE`) |
| The Taxi transport library, including the Zircon IP stack | `submodules/taxi` (git submodule, unmodified) | **CERN-OHL-S-2.0**, or a commercial license from FPGA Ninja. Two small files used here (`taxi_axis_if.sv`, `taxi_axis_tie.sv`) are MIT. |
| AMD IP in the block design: Versal CIPS, NoC, MRMAC, GT quad, AXI DMA, AXI-Stream width converters, clocking wizards, processor system resets, AXI IIC, AXI GPIO, SmartConnect | generated by Vivado | AMD's Vivado tool license. The MRMAC needs a no-cost license key. |

The repository's `submodules/README.md` lists exactly which Taxi modules the design uses, file by
file, with the license of each. Every source file carries an SPDX header stating its own license.

## What the CERN-OHL-S-2.0 means for you

The CERN Open Hardware Licence v2, Strongly Reciprocal (CERN-OHL-S) is a *copyleft* license for
hardware designs, similar in spirit to the GPL:

* You may use, study, modify and build the design, including for commercial purposes.
* If you **distribute a product** that contains the Taxi sources or a design derived from them,
  and a bitstream or device image counts, you must make the **complete source** of that design
  available to the recipients under the same license, including your own modifications and the
  parts of the design that are combined with Taxi.
* The MIT license of Opsero's parts does not change that obligation for the Taxi-derived part of
  your design.

If that is not acceptable for your product, FPGA Ninja offers a **commercial license** for Taxi
(info@fpga.ninja); see the [Taxi README](https://github.com/fpganinja/taxi). This page is a
summary, not legal advice: read the license text in `submodules/taxi/LICENSE` and take advice if
you are unsure.

## Rules this repository follows

* Taxi files are referenced from the submodule by path and never copied into the MIT-licensed
  tree.
* No CERN-OHL-S code is pasted into MIT files. The MIT glue talks to Taxi modules only through
  their ports.
* The submodule is pinned to one Taxi commit (`cc70b27`; `git submodule status` shows it). Zircon
  is under active development and its metadata format still changes, so the submodule is only
  updated deliberately, with the simulation testbench re-run.
