# Documentation for the 2x QSFP28 FMC Zircon Ethernet design

The documentation for this reference design is hosted at
<https://qsfp28-zircon.ethernetfmc.com> and it is best viewed from there.
This folder of the repo contains the sources for the documentation, and we strongly encourage
you to contribute to the documentation if you're interested in doing so. To contribute, you can
modify these sources and then make a pull request to this repository on Github.

The pages are MyST Markdown, rendered as Jinja2 templates against `config/data.json` (the target
design tables are generated from it), so add or change a target design in `data.json`, not in the
pages. The "Cross-platform build runner" part of `source/build_instructions.md` is generated by
Opsero's `gen_docs_buildflow.py` tool; edit the other sections only.

`DESIGN_SPEC.md` (in this folder, not part of the rendered site) is the working contract between
the RTL, the block design and the software.

## How to build the docs locally

You need Python 3 with Sphinx, the MyST parser and the ReadTheDocs Sphinx theme. The versions used
by Read the Docs are pinned in `requirements.txt`:

```
python3 -m venv sphinx_venv
source sphinx_venv/bin/activate
pip install -r <path-of-this-repo>/docs/requirements.txt
sphinx-build -b html <path-of-this-repo>/docs/source <path-of-this-repo>/docs/build/html
```

To view the locally generated docs, open `<path-of-this-repo>/docs/build/html/index.html` in a
web browser.
